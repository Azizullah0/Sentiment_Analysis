# Multiclass Sentiment Analysis for Low-Resource Social Media Text

## Overview
This project focuses on multiclass sentiment analysis for low-resource social media text, with an emphasis on Dari/Persian. It explores NLP and machine learning methods for sentiment classification in an underrepresented language setting.

## Objectives
- preprocess and analyze social media text
- perform multiclass sentiment classification
- explore challenges in low-resource language settings
- evaluate model behavior and results

## Tech Stack 
- Python
- NLP
- Machine Learning
- Data Analysis

## Repository Structure
- `config/` configuration files
- `scripts/` main scripts for preprocessing, training, or evaluation
- `utils/` helper functions
- `docs/` reporting of work
- `augmentations/` scrip for augmentations

This project was developed as part of academic project work in Computer Science and strengthened my skills in NLP, text classification, machine learning, and data-driven evaluation.
